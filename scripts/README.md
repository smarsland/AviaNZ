# Utility Scripts

This folder contains **standalone utility scripts** that support the main experiment pipeline but are not part of the core codebase.

## Main Entry Point

The main experiment pipeline is now in the **project root**:
- **`run_matched_experiments.sh`** - Main orchestration script for running all experiments
  - Automatically builds matched datasets
  - Loads noise data from freefield recordings if available
  - Runs all cross-dataset experiments (normalization, DANN, noise augmentation, merged)

## Main Data Processing

Core data loading is handled by:
- **`src/data/dataset_builder.py`** - Unified data loader
  Commands:
  ```bash
  # Load bird annotation data
  python src/data/dataset_builder.py avianz /path/to/data /path/to/output
  python src/data/dataset_builder.py doc /path/to/data /path/to/output
  
  # Load noise/environmental audio
  python src/data/dataset_builder.py noise /path/to/freefield /path/to/output --samples 1000
  ```

## Script Categories

### Experiment Support Utilities

- **`cleanup_incomplete_experiments.py`** - Deletes incomplete experiment folders (missing result.json)
  ```bash
  python scripts/cleanup_incomplete_experiments.py [experiments_dir] [results_dir]
  ```

- **`collect_results.py`** - Aggregates experiment results into summary JSON
  ```bash
  python scripts/collect_results.py <output_folder>
  ```

### Data Analysis & Validation

- **`count_species.py`** - Analyzes species distribution in datasets
  ```bash
  python scripts/count_species.py <data_folder>
  ```

- **`generate_ground_truth.py`** - Converts labels to CSV format
  ```bash
  python scripts/generate_ground_truth.py <data_folder>
  ```

### External Model Evaluation

- **`evaluate_birdnet.py`** - Evaluates BirdNET baseline on test datasets
  - **Note:** Requires audio files (not generated by standard pipeline)
  - Standalone utility for external model comparison
  ```bash
  python scripts/evaluate_birdnet.py <test_set1> <test_set2> --output results/
  ```

## Organization

**Do not put experiment pipeline scripts here.** Those belong in:
- **`src/experiments/`** - Core experiment modules (dataset building, training, evaluation)
  - `build_matched_datasets.py`
  - `split_matched_datasets.py`
  - `merge_datasets.py`
  - `validate_splits.py`
  - `run_cross_dataset_experiments.py`
  - `generate_pseudo_labels.py`
  - `analyze_dataset_quality.py`

**This folder is for:**
- One-off utilities
- Result analysis scripts
- External tools/baselines
- Cleanup/maintenance scripts
